# 基于 SpringBoot + Vue 的企业管理系统 (Enterprise Management System)

待办驱动 · 流程审批 · 考勤管理 · 会议协同 · 文档共享 · 财务费控 · 留言沟通 · 消息通知 · 三角色协同

本项目是一套面向中小企业的轻量级 OA + 协同办公管理系统，采用前后端分离架构，覆盖**管理员、企业（管理层）、员工**三类角色。系统围绕"组织架构、流程审批、考勤管理、会议管理、文档共享、财务费控、请假管理、留言沟通、消息通知"等核心业务设计，支持从员工自助申请、流程审批流转、考勤记录统计、会议协同安排、文档共享管理到财务申请支付、留言沟通反馈、消息实时通知的全链路数字化办公，实现企业内部管理规范化、流程自动化、信息透明化，适用于中小企业、创业团队、多部门协同组织等场景。

## 核心特性

- **待办任务驱动**：以"待办任务"为核心工作入口，自动聚合审批任务、会议提醒、考勤异常、消息通知等，按优先级排序并标注截止时间，逾期未处理自动预警，提升办公效率。
- **流程审批引擎**：支持自定义审批流程（请假、财务申请等），支持多级审批、条件分支、加签/转办/驳回，流程全程留痕可追溯，审批结果实时通知相关方。
- **考勤管理**：支持员工上下班打卡记录、请假申请与审批联动、考勤异常提醒，管理员/企业可按部门/时间维度统计考勤数据，生成月度考勤报表。
- **会议管理**：支持会议创建、参会人员通知、会议记录归档，员工可查看个人参会记录，企业可管理全部会议安排，实现会前通知、会中记录、会后归档全流程管理。
- **文档共享管理**：支持企业文档分类存储、权限控制、上传下载、在线预览，员工可查看权限范围内的共享文件，企业可管理文档目录与访问权限，实现知识沉淀与共享。
- **财务费控**：员工可提交财务申请（报销/借款/付款），企业端进行财务审核与支付，全流程记录申请、审核、支付状态，支持财务数据统计与对账。
- **请假管理**：员工在线提交请假申请（类型、时间、原因），企业端审批，审批通过后自动同步至考勤记录，支持请假统计与年假余额管理。
- **留言沟通**：员工可发布留言/问题反馈，企业可查看并回复，支持留言分类、状态跟踪（待回复/已回复/已关闭），构建内部沟通渠道。
- **消息通知中心**：集成站内消息、审批通知、会议提醒、考勤异常提醒等多种通知类型，支持已读/未读管理，确保重要信息及时触达。

## 功能模块概览

## 管理员端

管理员为平台运维角色，负责平台全局配置与多企业管理（若为 SaaS 多租户架构）：

### 平台管理

- **企业管理**：管理入驻企业/租户信息，包括企业名称、联系人、联系方式、企业地址、所属行业、企业规模、账户状态、开通时间、到期时间，支持企业启用/禁用。
- **管理员管理**：管理平台管理员账号，包括用户名、姓名、角色、权限范围、最后登录时间，支持新增/编辑/删除管理员。

### 全局数据

- **用户通知**：向全平台或指定企业发布系统通知，包括系统维护、规则变更、功能更新等，支持定时发布与已读统计。
- **数据统计**：平台级综合数据看板，展示企业数量、活跃员工数、今日待办数、流程审批量等核心指标，支持图表可视化。

## 企业端（管理层）

企业为系统的核心管理角色，负责本企业内部的全方位管理：

### 组织与人事

- **企业信息**：查看与编辑本企业基本信息，包括企业名称、Logo、地址、联系方式、企业简介、行业类别。
- **部门管理**：管理企业内部组织架构，支持树形部门结构（如总部→各部门→各科室），包括部门名称、负责人、上级部门、部门描述，支持部门增删改查与排序。
- **岗位管理**：管理企业内部岗位体系，包括岗位名称、所属部门、岗位职责、岗位级别、编制人数，支持岗位与员工关联。
- **员工管理**：管理本企业员工档案，包括姓名、工号、所属部门、岗位、手机号、邮箱、入职日期、在职状态、直接上级，支持员工账号启用/禁用与批量导入。

### 流程审批

- **请假审核**：审核员工提交的请假申请，查看请假详情（申请人、请假类型、起止时间、原因、附件），执行审批操作（同意/驳回），审批通过后自动同步至考勤记录。
- **财务审核**：审核员工提交的财务申请（报销/借款/付款），查看申请详情（申请人、申请类型、金额、事由、发票附件），执行审批操作（通过/驳回），审批通过后进入支付环节。
- **员工待办**：查看本企业内员工的待办任务汇总，包括待审批流程、待处理任务、待参加会议等，支持任务分配与进度跟踪。

### 考勤与会议

- **考勤记录**：查看本企业全部员工的考勤记录，包括打卡时间、请假记录、加班记录、异常考勤（迟到/早退/缺卡），支持按部门/时间筛选与月度考勤统计报表导出。
- **会议记录**：管理本企业全部会议，包括会议创建、参会人员通知、会议纪要归档，支持按时间/部门/参会人筛选查看历史会议记录。

### 文档与财务

- **文件管理**：管理企业共享文档库，包括文档分类（制度文件、培训资料、项目文档等）、上传/下载/删除、权限设置（公开/部门可见/指定人员可见），支持文档版本管理与在线预览。
- **财务支付**：对已审核通过的财务申请执行支付操作，记录支付金额、支付方式、支付时间、支付凭证，支持支付状态跟踪与财务对账。

### 沟通与通知

- **留言记录**：查看员工发布的留言/问题反馈，包括留言内容、发布时间、留言人、处理状态，支持回复留言与关闭已解决的留言。
- **员工通知**：向本企业员工发布内部通知，包括公告、政策变更、活动通知等，支持指定部门/全员推送与已读统计。
- **消息记录**：查看本企业内的消息往来记录，包括系统消息、审批通知、会议提醒等，支持消息搜索与归档。

## 员工端

员工为系统的普通用户，专注于个人办公事务处理：

### 账号与个人

- **员工信息**：查看个人基本信息，包括姓名、工号、所属部门、岗位、联系方式、入职日期，支持查看个人考勤与请假历史。
- **修改密码**：支持员工自主修改登录密码，保障账户安全。

### 考勤与请假

- **我的考勤**：查看个人考勤记录，包括每日打卡时间、请假记录、加班记录、考勤异常提醒，支持月度考勤统计查看。
- **请假申请**：提交请假申请，填写请假类型（事假/病假/年假/调休等）、起止时间、请假原因、上传附件（如病假证明），提交后等待企业审批，可跟踪审批进度。

### 任务与会议

- **我的任务**：查看分配给个人的待办任务，包括任务名称、截止时间、优先级、任务状态（待处理/进行中/已完成），支持任务进度反馈与完成确认。
- **会议记录**：查看个人参与的会议记录，包括会议时间、地点、参会人员、会议纪要、待办事项，支持会议提醒与纪要查看。

### 文档与财务

- **共享文件**：浏览企业共享文档库中权限范围内的文件，支持按分类筛选、关键词搜索、在线预览与下载。
- **财务申请**：提交财务申请（费用报销/借款/付款申请），填写申请类型、金额、事由、上传发票等附件，提交后等待企业审核，可跟踪审批与支付进度。

### 沟通与消息

- **留言发布**：发布留言/问题反馈，填写留言标题、内容、分类（建议/问题/投诉等），提交后等待企业回复，可查看历史留言与回复记录。
- **员工沟通**：与企业内部同事进行沟通交流，支持查看同事基本信息（部门、岗位、联系方式），便于工作协同。
- **我的消息**：查看个人收到的所有消息，包括审批通知、会议提醒、考勤异常提醒、系统公告等，支持已读/未读管理与消息搜索。
